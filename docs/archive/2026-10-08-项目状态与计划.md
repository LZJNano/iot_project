## 4. 已经解决的问题(本次)

### 4.1 broker 自测 ✅
- VM 上 `mosquitto_pub` 发到 `test`,`mosquitto_sub` 收到 ✅
- mosquitto 0.15 没有 `-W`/`-C`,用 `timeout 3 mosquitto_sub ...` 包装即可

### 4.2 RPATH 写死成 VM 路径(已修)
- **问题**:之前 binary 的 RPATH/RUNPATH = `/home/linux/iot_project/install/lib`,lab box 没有这条路径
- **改法**:Makefile 链接选项从 `-Wl,-rpath,$(INSTALL_DIR)/lib` 改成 `-Wl,-rpath,'$$ORIGIN'`,这样 binary 找同目录的 lib
- **下一步**:在 VM 上重 build,确认 RPATH 正确,再部署

### 4.3 `config.h` 里的 broker IP 是错的(已改)
- 原来:`192.168.1.105`
- 现在:`192.168.100.192`(桥接后的 VM IP,跟 uboot nfsroot 一致)
- 命令行仍可覆盖:`./mqtt_iot <broker_ip>`

### 4.4 lab box `/lib/libmosquitto.so.1`(不修)
- 是 v1,跟我们的 v0 二进制不兼容
- 但 lab box 默认从 `/lib/` 找,如果部署目录里有 `.so.0`,按 RPATH 同目录优先,先用部署目录的
- **不修,留作 known issue**

### 4.5 `/source/rootfs/dev/` 是空的(暂不管)
- 启动后 `insmod dht11.ko` 会自动 mknod `/dev/dht11`
- 模块在 `/source/rootfs/lib/modules/3.4.39-farsight/extra/dht11.ko`
- 真不行就手动 `mknod /dev/dht11 c <major> <minor>`,或重新编 dht11 驱动
