# 信通学院电子信息工程专业

## “智能硬件系统课程设计” 任务书

**题目**：智能硬件系统 IOT 应用开发

### 主要内容

学习和掌握构建基于智能硬件平台和嵌入式 Linux 软件开发环境的方法，掌握物联网平台原理和接入方法，配置设备联网实现某种云平台的设备接入和 MQTT 数据通信，实现本地传感器数据上报和设备远程控制等功能。

### 设计要求

基本要求：某种云平台的设备接入或者本地 MQTT 服务器接入，智能硬件平台上实现传感器数据上报和远程控制。

扩展部分：图形环境下，设计图形应用程序实现设备和云平台数据交互。

### 主要仪器设备

1、智能硬件开发系统 1 套
2、计算机 1 台，安装 Ubuntu 操作系统及 arm‑linux 交叉编译工具
3、网线 2 根，IP 地址 2 个

### 课程设计进度计划（起止时间、工作内容）

第 1‑2 周：掌握构建嵌入式 Linux 开发环境及开发应用程序的基本方法；理解所选题目要求，学习相关知识，搭建相应软件和硬件环境；完成基本要求，完成云平台设备接入和数据上报。

第 3‑4 周：进一步完善功能，并进行扩展要求设计，完成课程设计报告，现场检查、答辩。

课程设计期间的其它时间实验室也一直开放，需要实验的同学在遵守实验室管理规定的条件下可以随时进行实验。课程设计报告在课程设计答辩时提交。
