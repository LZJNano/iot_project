# 8. 总结

通过本次课设,我进一步深入了解了嵌入式 Linux 系统,并且系统性地掌握了 MQTT 协议在物联网中的应用。具体来说,我在 FS6818 实验箱上完成了从内核驱动加载(GPIOD25/GPIOC7 等 GPIO 复用)、用户态 libmosquitto 客户端封装,到设备节点 `/dev/dht11` 自动 mknod 的完整嵌入式开发链路;同时在调试 NFS 网络根文件系统和串口终端的过程中,我加深了对 VMware 桥接 vs NAT 两种网络模式差异的理解,以及"实验箱从 uboot 启动到 Linux 跑起来"这一嵌入式系统引导链路的整体认知。

通过本次课设,我初次完整地用 Qt 编写了桌面端应用,初次用 C 语言组织了一个跨模块、跨线程的中小型设备端项目,并且初次亲手把"控制按钮"和"硬件响应"用 MQTT 主题匹配连起来。这中间踩了不少坑——比如 FS6818B 板子 LED 逻辑反相、实验箱 rootfs 的 `/dev` 是空目录、DHT11 驱动返回的字节序跟 mqtt_iot 注释不一致——但每次 debug 后都加深了对"硬件数据手册不可全信,实测是发现问题的关键"这一工程原则的理解。

本次实践课程是上学期"智能硬件系统"课程的综合实践。此前我接触过一些嵌入式和物联网项目,也接触过 MQTT 协议的 PLC 控制项目,但**完整跑通"从传感器到控制端"全流程,还是第一次**;**自建 broker 并自己管理订阅与消息路由,也是第一次**。这两层"第一次"让我对物联网系统的端到端开发有了完整的认知——从嵌入式 C 程序设计、Qt 桌面 GUI 编程,到三方联调与协议层解耦设计,都有了第一手经验。

感谢老师在课设期间的指导,以及为这次实验做准备的幕后工作者。通过本次实验我收获满满,也期待未来能在更具挑战性的课题中再次实践。
