# 前言

本书从基础知识、系统环境搭建到综合应用，共分三个层次深入浅出地为读者拨开萦绕于嵌入式
这个概念的重重迷雾，引领读者渐渐步入嵌入式的世界，帮助探索者实实在在地把握第三次IT 科技浪
潮的方向。本书的特色如下：
( 1 ) 重基础，适合教学。

( 2 ) 重素质，全面讲解。本书在一般性教材的基础上，对嵌入式系统的软硬件开发环境进行了大
量的讲解，可以让读者更进一步、更全面地了解嵌入式的开发过程。

( 3 ) 重实践，与实际项目相结合。本书每个原理讲解都对应着丰富的实验内容，并且原理讲解和
实验内容一一对应，使得每个知识都可以被深刻的理解运用，本书附带的光盘中给出了参考设计代码
和文档。

( 4 ) 重应用。书中的实例对时下经常使用的功能、设备、器材进行讲解和说明，力求教材所涉及
的内容能紧跟行业实际应用的需要。

如无特殊说明，本书实验所用内核的版本均为Linux3.4.39，u-boot 的版本均为
2014.07 版

# 第 1 章  平台概述

华清远见 ARM EMB6818 开发平台（下文简称EMB6818）是由华清远见研发中心专为培训教学和项
目研发定制的高性能的ARM Cortex-A53 开发平台和控制性能优越的ARM Cortex-M4 平台。EMB6818 是由
华清远见研发中心采用 S5P6818 主芯片研发设计的一款稳定性强、可靠性高的成熟三星八核方案产品，
该产品主频高达1.4GHz+，集成Mali-400 MP4 图形处理器，支持3D 图形流畅运行，并可播放1080P 大尺
寸高清视频。EMB6818 开发板配置 2GB 双通道 DDR3 的内存及 16GB 存储，内置有WIFI 、蓝牙4.0 模
块、500W 自动对焦Camera、IR、LVDS/Mipi 屏接口等模组，支持HDMI1.4（1080P/60Hz）显示。工作主
频1.4G，DDR 主频跑1866/933MHz，7X24 小时连续运行不死机。客户可以直接从开发平台中汲取完整的
产品信息，甚至可以直接用于后续的产品开发中，完全不同于一般意义的开发平台。

### 2.3.1 Reset/Power/Volume 按键

FS_EMB6818 开发平台（版本不同可能替换为拨码开关）包含4 个按键。包含1 个Reset 复位按键
（长按复位的模式），1 个Power 电源按键、2 个音量控制按键，1 个home 主页键，1 个break 返回键。

其中Reset 复位按键的设计方便了开发人员调试，而Power 和Volume+/-按键的则完全按照现在主流
的手机和平板的设计。其中Power 键作为开发板的电源按键，可以使开发板唤醒或者睡眠，Volume+/-按
键则可以调节Android 下的音量。而且，FS_EMB6818 平台还具备类似同时按住Power 键和Volume - 按
键，以对Android 的当前屏幕截图等实用的功能。home 键可快速回到主屏幕，break 键可回退回下一菜
单。

（电量剩余50%-30%）红色（电量剩余20%-10%）进行实时变化。

( 6 ) 节点上方显示的文字含义依次为：节点名称，节点状态或者数据。

( 7 ) 例如：烟雾 2730 显示的是传感器采集的分压值，具体含义请参考底层实验。红外 关，表示的是当

## 4.4  重点文件说明

【重点文件说明】
编译后生产文件中我们需要烧写到设备上有五个文件，分别是ubootpak.bin、boot.img、
system.img、cache.img 和userdata.img。

ubootpak.bin：包括2ndboot.bin、nsih 和u-boot.bin 三个文件
boot.img：包括zImage 和ramdisk.img 和开机LOGO 图片
system.img：android 文件系统
cache.img：缓存文件
userdata.img：用户数据文件
【编译脚本mk 参数简介】
在以下实验中会用到mk 这个脚本来编译源码，下面是对该脚本的参数介绍：

-u：只编译bootloader 源码，生成ubootpak.bin；

-k：只编译内核源码，生成uImage；

-b：编译内核源码并将生成的uImage 及开机logo 打包成boot_linux.img；

-s：编译安卓源码，并打包成安卓必须镜像，执行该参数前需确保bootloader 及内核已经编译；

-a：执行-u、-k、-s 三个操作，便编译安卓源码使用该参数即可。
