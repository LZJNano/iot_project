FS_EMB6818实验箱

> 图片：FS_EMB6818实验箱

清华远见ARMEMB6818开发平台是由华清远见研发中心为培训教学和项目研发定制的高性能的ARMCortex-A53开发平台和控制性能优越的ARMCortex-M4平台。该产品的主频高达1.4GHz+，集成Mali-400MP4图形处理器，支持3D图形流畅运行，并可播放1080P大尺寸高清视频。EMB6818开发板配置2GB双通道DDR3内存及16GB储存，内置有WIFI、蓝牙4.0模块、500W自动对焦Camera、IR、LVDS/Mipi屏接口等模组，支持HDMI1.4显示。工作主频1.4G，DDR主频跑1866/933MHz，7×24小时连续运行不死机。

DHT11数字温湿度传感器是一款含有已校准数字信号输出的温湿度复合传感器，它应用专用的数字模块采集技术和温湿度传感技术，确保产品具有极高的可靠性和卓越的长期稳定性。传感器包括一个电阻式感湿元件和一个NTC测温元件，并与一个高性能8位单片机相连接。因此该产品具有品质卓越、超快响应、抗干扰能力强、性价比极高等优点。每个DHT11传感器都在极为精确的湿度校验室中进行校准。校准系数以程序的形式存在OTP内存中，传感器内部在检测信号的处理过程中要调用这些校准系数。单线制串行接口，使系统集成变得简易快捷。超小的体积、极低的功耗，使其成为该类应用中，在苛刻应用场合的最佳选择。产品为4针单排引脚封装，连接方便。

### 2. 阿里云平台配置

#### （1）阿里云平台介绍

阿里云物联网平台为设备提供安全可靠的连接通信能力，向下连接海量设备，支撑设备数据采集上云；向上提供云端API，服务端通过调用云端API将指令下发至设备端，实现远程控制。

阿里云平台提供了以下服务：

1. **IoT SDK**：物联网平台提供IoT SDK，设备集成SDK后，即可安全接入物联网平台，使用设备管理、数据流转等功能。只有支持TCP/IP协议的设备可以集成IoT SDK。
2. **IoT Hub**：IoT Hub帮助设备连接阿里云物联网平台服务，是设备与云端安全通信的数据通道。IoT Hub支持PUB/SUB与RRPC两种通信方式，其中PUB/SUB是基于Topic进行的消息路由。
3. **数据分析**：数据分析是阿里云为物联网开发者提供的数据智能分析服务，针对物联网数据特点，提供海量数据的存储备份、资产管理、报表分析和数据服务等能力，帮助企业用户更容易地挖掘物联网数据中的价值。
4. **设备管理**：物联网平台为您提供功能丰富的设备管理服务，包括：生命周期、设备分组、设备影子、物模型、数据解析、数据存储、在线调试、OTA升级、远程配置、实时监控等。
5. **云产品流转**：当设备基于Topic进行通信时，您可以编写SQL对Topic中的数据进行处理，然后配置转发规则将数据转发到其他Topic或阿里云服务上进行存储和处理。
6. **安全认证和权限政策**：安全是IoT的重要话题。阿里云物联网平台提供多重防护，保障设备和云端数据的安全。

1. 打开 LinkSDK 中 demo 文件夹的 `data_model_basic_demo.c` 文件，将 main 函数中的 product key、device name 和 device secret 换成自己创建的设备证书的信息，细节请参见下图：

> 图9 用户创建设备证书，更改三元组代码

2. 使用MQTT连接物联网平台，具体设置方式根据 `data_model_basic_demo.c` 文件中的 `main()` 函数了解MQTT连接的初始化过程。

3. 修改 `data_model_basic_demo.c` 文件中的属性上报函数 `demo_send_property_post()` 上报设备属性，同时结合实验箱中提供的DHT11演示实例进行移植，对温湿度传感器每十秒钟进行一次读取，完成数据的收发。

```c
int32_t demo_send_property_post(void *dm_handle) {
    int fd;
    fd = open("/dev/dht11", 0_RDWR);
    unsigned char buf[4];
    char *propertyFmt = "\num\":%d, \*temperature\":%d";
    int32_t temperature;
    int32_t hum;
    int a;
    a = read(fd, buf, sizeof(buf));
    hum = buf[3];
    temperature = buf[1];
    printf("hum = %d, temp = %d\n", hum, temperature);
    char property_params[256] = {0};
    aiot_dm_msg_t msg;
    close(fd);
    snprintf(property_params, sizeof(property_params), propertyFmt, hum, temperature);
    memset(&msg, 0, sizeof(aiot_dm_msg_t));
    msg.type = AIOT_DMMSG_PROPERTY_POST;
    msg.data.property_post.params = property_params;
    return aiot_dm_send(dm_handle, &msg);
}
```

## 七、问题及总结

通过对用阿里云物联网平台，我们设计了一个简单的智能设备控制和接入软件的系统，用于环境温度的监测。我们也能通过手机应用APP实现对数据进行远程监测和管理等功能，并可以实施线上关机。

在环境开发时，我们也因为对操作环境不熟练，把开发板的官方例程移植到阿里云时，由于在程序的循环中文件打开/关闭操作不当，导致读数错误；对json数据格式不熟悉，代码的编译也都进行了相应资料的查阅和参考。

此次通过对智能环境监测系统进行开发和设计，我们对阿里云物联网平台的开发，环境设置，设备证书的创建等一系列过程都有了一定的了解，通过实际动手操作，进一步知晓了其中流程。通过路由器连接网端，将监测数据进行导入，需要更改初始化环境，上报模拟设备属性，进而完成数据的接收发。

在实验的进行过程，组员之间良好的协作配合也是十分重要的，从前期任务分配，到实际操作中问题发现，设备调试，互相配合，才能得到成果。
